Rule format

Each rule has the form Kind:Value. Multiple rules of the same kind are allowed.

Title:<text>
Matches when the normalized event title starts with the normalized text. Normalization replaces punctuation with spaces, collapses whitespace, and ignores case.
Name:<name>
Matches an individual name anywhere in the event's name lists. The match is exact and case-insensitive.
Group.Name:<group>.<name>
Matches a name listed beneath the specified group heading. For example, Group.Name:Uncles.Bob matches Bob beneath an Uncles heading. Group names are lowercased and depluralized before comparison.
FullText:<text>
Matches normalized text anywhere in the event title or description.
