# Filter file for Find-Rehearsals.ps1
#
# Each non-blank, non-comment line is one match rule in the form Kind:Value.
# A calendar event matches if ANY rule below matches it. Lines starting with
# '#' and blank lines are ignored. It's OK to have multiple rules of the same
# kind (e.g., more than one Title rule).
#
# Rule kinds:
#
# - Title:<text>
#
#   Matches if the event's normalized title starts with normalized <text>.
#   Normalization replaces punctuation with spaces, collapses whitespace, and
#   lowercases - e.g. "Living Room - Adults"
#
# - Name:<name>
#
#   Matches if <name> appears as an individual name anywhere in the event
#   body's name lists (exact match, case-insensitive). Use this if a cast
#   member's name is unique within the cast.
#
# - Group.Name:<g>.<n>
#
#   Matches if the name <n> appears in a name list with the heading "<g>:".
#   For example, if a calendar entry has "Uncles: Bob, Fred", then the
#   rule is true if <g> matches "Uncles" and <n> matches "Bob" or "Fred".
#   Group names are converted to lowercase and depluralized.
#
# - FullText:<text>
#
#   Matches if <text> appears anywhere in the calendar entry's title or body.
#   Text is normalized in the same way as the Title rule.

Title:Living Room All
Title:Living Room Adults
Group.Name:Uncles.Nick
